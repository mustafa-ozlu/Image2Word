# Image2Word

Resim dosyalarındaki metinleri Word dosyası haline getirmek için Python ile yazılan kod.
C:\Resimler klasörünü tarar ve **C:\Resimler** altında **OUTPUT.docx** dosyasına yazar.

Kaynak kodu kullanmak için 
```python
pip install pytesseract python-docx
```
kütüphaneleri yüklenmelidir.

*Release sayfasındaki EXE halinde herhangi bir ekstra kütüphane kurma ihtiyacı yoktur.*
